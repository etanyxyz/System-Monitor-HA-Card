# Changelog

## 0.1.2

- Docs only: accurate build-from-source monitor setup (there is no published
  image), Marketplace-first install steps, release/license badges.

## 0.1.1

- Hide the swap bar when the host has no swap configured (shows “swap disabled”).
- Log the loaded card version to the browser console so a cached copy is easy
  to spot.
- Docs: Marketplace-first install steps.

## 0.1.0

- First release: CPU ring gauge, per-core bars, memory/swap bars and Docker
  container rows with state badges and live CPU/memory.
- Queue param (`?token=`) and `Authorization: Bearer` token support.
- Visual card editor (URL, token, interval, title, container limit).
- Container queries adapt the layout to narrow dashboard columns.
